FIRE to IRIS

FIRE is changing. Your infrastructure has to change with it.

The IRS is transitioning information-return filing from the legacy FIRE system to IRIS. For software companies that have built or depend on filing infrastructure, this creates a significant migration and integration requirement.

Prepare your filing stack for IRIS

Move from legacy filing workflows without rebuilding everything.

Keep your existing data model. Let IrisTaxFiling handle the translation, validation, and filing workflow.

curl https://api.iristaxfiling.com/v1/filings \
  -H "Authorization: Bearer $IRISTAXFILING_KEY" \
  -H "Idempotency-Key: 2026-nec-0001" \
  -d @filing.json
const res = await fetch("https://api.iristaxfiling.com/v1/filings", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.IRISTAXFILING_KEY}`,
    "Idempotency-Key": "2026-nec-0001",
    "Content-Type": "application/json",
  },
  body: JSON.stringify(filing),
});
const { id, status } = await res.json();
import os, requests

r = requests.post(
    "https://api.iristaxfiling.com/v1/filings",
    headers={
        "Authorization": f"Bearer {os.environ['IRISTAXFILING_KEY']}",
        "Idempotency-Key": "2026-nec-0001",
    },
    json=filing,
)
print(r.json()["status"])
using var http = new HttpClient();
http.DefaultRequestHeaders.Add("Authorization",
    $"Bearer {Environment.GetEnvironmentVariable("IRISTAXFILING_KEY")}");
http.DefaultRequestHeaders.Add("Idempotency-Key", "2026-nec-0001");

var res = await http.PostAsJsonAsync(
    "https://api.iristaxfiling.com/v1/filings", filing);
